# retro-purple

purple bevels + original tiny file/folder icons. data only. pick retro purple in appearance after loading.

## grants

none. data-only assets.

## check it

from the repo root:

```sh
swift run --package-path Packages/ModValidation betterfinder-mod validate examples/retro-purple
```

validate runs a dry run of every hook and any `tests/*.bftest.json`, then prints pass or fail. for the visible check, load it in a scratch window (Mods → Load Unpacked Mod…) after native approval.

select retro purple in appearance; expect purple selection and purple file/folder icons. switch back to modern; expect system appearance. disable the mod; its assets should disappear.

see [authoring guide](https://github.com/bryanthaboi/betterfinder/wiki/Getting-Started). nothing auto-enables. license: MIT.
